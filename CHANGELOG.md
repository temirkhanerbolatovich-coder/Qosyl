# Изменения Qosyl

05.11.2026 — опубликованы проверенные возможности и справочные материалы; добавлен скрипт зашифрованной копии БД на Windows с проверкой целостности. Проверка SMTP показала получение письма в спаме. [Результаты контента](docs/qa/content-publication-2026-11-04.md), [резервирование](docs/deployment/offvm-backups.md), [почта](docs/qa/mail-delivery-2026-11-04.md).

04.11.2026 — [выпуск опубликован](docs/qa/release-2026-11-04.md): CI на GitHub успешен, расширения профиля/аватара/кейсов и исправления интерфейса перенесены на Oracle. Перед шестью миграциями проверено восстановление свежей копии БД; прежние записи сохранены. Записи о локальной подготовке ниже отражают предыдущие этапы.

04.11.2026 — подготовлен локальный [workflow GitHub CI](docs/testing/ci.md): Node 24, временный PostgreSQL 18 и последовательные проверки кода, сборки, API, зависимостей, E2E и UI. Actionlint и отрицательные проверки workflow/случайного `test.only` прошли; hosted run, публикация workflow и настройка required check остаются открытыми.

04.11.2026 — локальная стабилизация, ещё не опубликована: доступные отдельные email/Google-формы с 24 px флажками и разделителем; сохранение размера бренда в планшетной шапке; актуальные E2E-селекторы и синтетические OAuth-параметры тестов. Caddyfile разрешает 2 МиБ только для POST аватара, сохраняя прочие пределы; добавлена проверка настоящим локальным прокси. [Проверки, статус и ограничения](docs/qa/stabilization-2026-11-04.md).

29.10.2026 — расширена ExternalPortfolioItem без пересоздания записей: поля кейса, приватность, явное разрешение публикации, revision и порядок. Новый API владельца, вкладка портфолио, маркировка происхождения. Старый bulk-save не заменяет существующие работы. [Контракт и откат](docs/portfolio-cases.md).

29.10.2026 — безопасный аватар: отдельная ProfileAvatar, ограниченное декодирование JPEG/PNG, удаление метаданных, публикация с согласием, отзыв доступа и проверка revision. Sharp закреплён напрямую. Миграция применена локально после backup/restore. [Проверки](docs/qa/profile-avatar-2026-10-29.md).

29.10.2026 — локально добавлены необязательные заголовок, курс, языки и структурированный опыт в существующий профиль. Закрытый опыт исключается из гостевой страницы и данных откликов заказчика; публикация самостоятельного опыта не присваивает подтверждение Qosyl. Аддитивные миграции проверены на непустой тестовой базе и применены локально после backup/restore. Новых таблиц и зависимостей нет.

29.10.2026 — добавлены регистрация и вход через Google с подтверждением возраста и условий при регистрации; автоматическое связывание с существующим email отключено. Развёрнуто на публичном сайте, подтверждена регистрация владельца и владение сайтом в Search Console; оформление бренда ожидает повторной проверки Google.

28.10.2026 — RU/KK специальных ошибок дат, HTTPS, закрытых вложений, согласий, источников, расходов и фильтров; добавлены две причины выбора действующего участника. Серверные правила и история без изменений.

28.10.2026 — ошибки JSON/схемы/сети в клиентах файлов, контента и лидов больше не выводят сырую диагностику. После подтверждённой команды ошибка обновления описывается отдельно; формы сохраняются при сбое. Добавлено чтение карточки/материала без повторной команды и проверки отрицательных ответов избранного.

28.10.2026 — инвентаризация ошибок F06: заполнены фиксированные сообщения файлов/модерации/портфолио/затрат и Threads; причины отказа проверки подключения сохраняются, некорректные ответы Threads дают понятное сообщение без сырой диагностики схемы.
