# Изменения Qosyl

## 2026-10-27 — состояния поиска и клавиатурная навигация

- Каталог возможностей различает загрузку, ошибку и подтверждённый пустой результат; доступна кнопка повторной загрузки без потери ввода.
- Повторный поиск с теми же условиями запускается корректно; pagination блокируется на время загрузки.
- Escape закрывает мобильную навигацию и возвращает focus на кнопку меню.
- Добавлены браузерные проверки медленного ответа, отказа/восстановления, мобильных фильтров и клавиатуры в обеих темах.

## 2026-10-27 — дизайн-система 1.0

- Deep Blue/Teal и единые semantic tokens для существующих страниц, controls и статусов.
- Light/Dark/System с сохранением preference и ранним применением темы; локальные Inter/Manrope WOFF2.
- Исходный пользовательский логотип в шапке, подвале и иконке сайта, улучшенные карточки и мобильная навигация.
- Расширенный UI QA на семи ширинах и в двух темах; API, роли, серверная логика и runtime dependencies сохранены.

## 2026-10-26 — инфраструктура UI Quality

- Repo skill, AGENTS-указатели, проверенный реестр источников, спецификация дизайн-системы и план без редизайна.
- Dev-only axe + Playwright baseline/strict gate на четырёх ширинах; проверка контраста предложенных токенов. Исходные src-файлы и runtime dependencies сохранены.

## 2026-10-26 — общий поиск возможностей

- HTML и RSS в существующем ограниченном worker; поддержка карточек мероприятий Astana Hub.
- Каталог `/opportunities`, поиск закрытой очереди, фильтры по типу, направлению и географии; корректный регистр RU/KZ при C-локали PostgreSQL.
- Гранты, стипендии, обучение, новости и статьи. 109 реальных материалов из семи источников в закрытой очереди без автоматической публикации. Добавлены KazNARU, Abai University и университет туризма; исправлены классификация прошедших событий и извлечение описаний из карточек-ссылок.
- Изолированная временная БД для повторяемых контентных integration-тестов; прежняя история сохранена.
