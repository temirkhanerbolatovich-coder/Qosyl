Текстовые извлечения DOCX предназначены для поиска: таблицы вынесены после абзацев, оригинальная вёрстка не воспроизводится. Новые DOCX/XLSX не создавались.

## Что не выполнялось в этом проходе

Production build, E2E, повторный браузерный проход, запуск приложения, миграции, restore, реальная доставка SMTP, внешний security audit, нагрузочные проверки, новое открытие всех веб-источников, live-проверка API соцсетей. БД и production-конфигурация не менялись.

`../../../docs/qa/local-demo.md` содержит историческую запись 15/15 E2E, сборки и восстановления. Она изучена как ранее сохранённое свидетельство и не выдана за результаты текущего запуска. Новые тесты агрегатора пока невозможны: модуль не реализован.

## Сохранение рабочего пространства

Изменения текущей задачи ограничены Qosyl и производными локальными артефактами стандартных проверок. Код приложения, исходный research и пользовательские вложения не редактировались. Копии приватных материалов исключены из Git локальным `.gitignore` Qosyl.

При первичном архивировании файловый обход прошёл по ссылке на node_modules исследовательского инструмента. Осталась лишняя локальная копия в `../../../01_sources/research/scripts/node_modules`; автоматическая политика отклонила её удаление. Она исключена из манифеста содержательных материалов и Git; исходная ссылка и зависимости не менялись. Очистка этой копии остаётся служебным ограничением, не мешающим использованию документов.
