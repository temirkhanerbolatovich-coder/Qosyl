# ADR-010 Темы и бренд Qosyl

Статус: принято. Дата: 26.10.2026.

## Контекст

После инфраструктурного этапа пользователь явно запросил внедрение Deep Blue/Teal, двух тем, системного режима, Manrope/Inter и предоставил обязательный логотип. Существующие компоненты и бизнес-логика должны сохраниться.

## Варианты

Полная миграция на UI-kit/theme provider; либо обновление существующего CSS-контракта и небольшой отдельный переключатель. Выбран второй вариант: он не меняет API компонентов/маршрутов и не добавляет runtime dependencies. Tailwind остаётся существующим фундаментом сборки CSS; shadcn CLI и второй набор primitives не устанавливались.

## Решение

JSON — единственный редактируемый источник палитр/spacing/radius; CSS генерируется и проверяется. Старые названия CSS-переменных оставлены как алиасы, чтобы существующие компоненты использовали новую семантику без массового изменения классов. Для мелкого текста Teal отличается от заливки action: реальные проверки обнаружили недостаточный контраст базового цвета на tinted surfaces.

Статический ранний head-script устанавливает только валидированные data-атрибуты темы. Сохраняется исключительно несекретная preference light/dark/system; системные изменения и storage events обрабатываются клиентом. При блокировке storage работает выбор текущего документа. Существующая CSP не ослабляется. suppressHydrationWarning относится только к преднамеренно различающимся root-атрибутам, не скрывает ошибки дочерних компонентов.

Шрифты локальные WOFF2 с лицензиями, logo — неизменённая копия файла пользователя. В dark logo остаётся на исходном белом фоне; искусственная инверсия не выполняется. CSS color-scheme согласует native controls с темой.

## Последствия

Настройки сохраняются без учётной записи, аккаунтные данные не затрагиваются. Есть немного legacy CSS, но все его HEX-значения вынесены в токены. Новый внешний набор компонентов следует вводить только при подтверждённой необходимости. Figma-файл, новые backend-функции и несуществующие модальные сценарии этой работой не создаются.
