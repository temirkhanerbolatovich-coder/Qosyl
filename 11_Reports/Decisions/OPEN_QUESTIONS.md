# Открытые вопросы Qosyl

Срез: 25.10.2026. Вопросы не означают, что решения приняты или функции реализованы.

| Вопрос | Почему требуется решение | Следующее действие |
|---|---|---|
| Кто оператор, модератор и ответственный за данные/жалобы? | Реальная эксплуатация требует назначенных людей | Владелец назначает роли и каналы поддержки |
| Какие две задачи готов покупать бизнес? | Интерес студентов не подтверждает спрос заказчика | Проверить конкретные офферы независимым покупателям |
| Период, бюджет и вместимость пилота; актуальна ли дата 30 октября? | Количественные цели концепции не задают ресурс и календарь | Уточнить перед обещанием сроков |
| Монетизация и предел защиты оплаты | 35/45 хотят гарантию, MVP её не предоставляет | Сохранить честное описание; выбрать отдельный эксперимент |
| Источники и доступы для агрегатора/Threads | ТЗ не подтверждает доступность социальных API | Сначала согласовать ручной ввод/RSS; доступы проверять отдельно |
| Публичная лента, приватные лиды и обсуждения | Концепция шире ТЗ агрегатора | Не смешивать их с подтверждёнными заказами |
| Правила дедупликации, редакций, дат и scoring | В ТЗ есть неоднозначности, сумма весов 105 при шкале 100 | Уточнить до разработки модуля; не менять исходник задним числом |
| Приёмка этапа 2 | Q10 принят: 133 unit, 14 SQL, 18 E2E; фоновые процессы ещё не реализованы | Завершить Q11 по актуальному progress.md |

## Материалы и ограничения хранения

- Неоднозначных кандидатов на удаление уникальных файлов не осталось: все такие материалы сохранены. Старая QA, cloud-retirement и исследования — история, а не мусор.
- В родительской папке осталась пустая скрытая `.git`. Её удаление отклонено автоматической проверкой; рабочие Git-данные находятся в `Qosyl/.git`, индекс проверен по SHA256. Это исключение из цели «только Qosyl».
- Исторические манифесты содержат прежние локальные пути и ссылки на внешние входные документы в Downloads/attachments. Они сохранены как сведения о происхождении. Доступность исходных внешних файлов не гарантируется переносимостью проекта.
- Исследовательские Node-инструменты используют внешний runtime через junction. Для другого компьютера зависимости нужно настроить отдельно; основной npm lockfile приложения сохранён.
- Архив до изменения путей нужен для проверки сохранности; его удаление сейчас не предлагается.
