# ADR-008: локальный сбор HTML и поиск по редакциям

Статус: принято. Дата: 26.10.2026.

## Контекст
Нужно собирать сайты и RSS с грантами, стажировками, мероприятиями и материалами разных специальностей. Существуют безопасный HTTPS transport, ContentSource, worker и редакционная история.

## Варианты
Crawlee/Playwright, отдельный Python scraper, облачные платные Actor либо расширение существующего worker с Cheerio.

## Решение
Добавить явный html режим и Cheerio к существующему проверенному transport. Не запускать браузер там, где доступен серверный HTML. Один новый пакет для корректного разбора HTML; лицензия MIT. Новых сервисов и платных API нет. feedUrl переиспользуется как адрес страницы; миграция расширяет ограничения типа и категории без удаления истории.

Поиск административной очереди использует последнюю редакцию, публичный — одобренную; SQL значения параметризованы, RU/KZ case-fold не зависит от локали базы. Каталог сохраняет существующую публичную проекцию.

## Последствия и риски
Нужны отдельные структурные правила для отличающихся сайтов. Разметка может измениться, JS-сайты не покрываются. Сбор не доказывает релевантность или доступность программы любому студенту. Все материалы сначала проходят ручную модерацию; дата/регион не угадываются. Источники выключаются независимо.

## Дальнейшая работа
Расширять подтверждённый реестр не-IT организаторов, уточнять извлечение дат/географии на уровне каждого источника. Браузерные/социальные адаптеры вводить отдельно с их собственными сессиями и проверками.
