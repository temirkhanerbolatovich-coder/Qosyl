# Local fonts

Retrieved 2026-10-26 from the official Google Fonts repository:

- Inter variable: https://github.com/google/fonts/tree/main/ofl/inter
- Manrope variable: https://github.com/google/fonts/tree/main/ofl/manrope

Both use SIL Open Font License 1.1. Copyright notices and licenses are included in Inter-OFL.txt and Manrope-OFL.txt. The variable TTF files were converted to WOFF2 using fontTools 4.67.0 with Brotli; glyph outlines and family names were not edited. Both include Russian Cyrillic. Inter covers the checked Kazakh letters; missing Kazakh glyphs in Manrope fall back to Inter through the heading font stack. Manrope's automatic Arial fallback is disabled so that fallback order remains explicit.

Assets total 404064 bytes. `next/font/local` serves them from this application with display=swap; no Google Fonts network access is needed at build or runtime. Provenance, byte counts and hashes: outputs/ui-quality/fonts.json in the repository root. These fonts' licenses do not apply to the separately user-supplied Qosyl logo.
