# Выбор инструментов UI Quality

Обновление после пользовательского запроса на внедрение: Deep Blue/Teal, Light/Dark/System и локальные Manrope/Inter уже применены без новых npm dependencies. [ADR-010](../11_Reports/Decisions/ADR-010-brand-themes.md) и [актуальная дизайн-система](design-system.md) дополняют приведённое ниже историческое решение инфраструктурного этапа.

Дата: 26.10.2026. Решение для первого этапа: оставить Next.js App Router 16.4.3, React/DOM 19.3.1, TypeScript 5.9.3, Tailwind/PostCSS 4.3.3, существующий globals.css и Lucide 1.61.0. Node 24.12.0 на Windows; npm/lockfile. Архитектура серверных компонентов, Better Auth, Prisma и API сохраняется.

## Принято сейчас

Только devDependency `@axe-core/playwright@4.14.0`, MPL-2.0. Требует Node >=22.12 и playwright-core >=1; установленные Node 24 и Playwright 1.64.1 подходят. Установлен точный номер, runtime-зависимости не добавлены. Собственный тестовый профиль переиспользует проверенную изоляцию БД/сервера и добавляет четыре ширины, screenshots, axe и наблюдение ошибок. Наличие peer-совместимости не заменяет реально выполненный запуск.

Собственный repo skill содержит оригинальные правила и ссылки. Сторонние skills изучены, но не установлены целиком: новый frontend-app-builder в открытом источнике требует Image Gen, задаёт свою методику согласования и целевой стиль для создания/редизайна. Это выходит за текущую задачу. Его команды не переносились в AGENTS. Anthropic frontend-design (Apache-2.0) полезен как методика предметного визуального направления; Vercel web-design-guidelines и react-best-practices (MIT) — как проверки и приоритеты оптимизации. Ни один не переопределяет пользовательский запрет менять UI.

## Матрица решений

| Кандидат | Применимость | Решение |
| --- | --- | --- |
| Tailwind, Grid/Flex | Уже используются; CSS-first токены совместимы с v4 | Сохранить, без переустановки |
| shadcn/ui | Код компонентов, а не готовая кнопка включения; CLI может менять CSS/config | Отложить до реальной потребности в компоненте |
| Radix UI / Base UI / React Aria | По metadata поддерживают React 19; нужен аудит конкретного компонента и client boundary | Если возникнет сложный dialog/combobox, выбрать один фундамент; сейчас не добавлять |
| TanStack Table 9.3.1 | React >=18, Node >=20; major v9 требует актуальной документации | Пока обычных таблиц достаточно; не переносить v8 примеры без проверки |
| TanStack Virtual | React 19 поддерживается; текущая выдача ограничена пагинацией | Не нужна без измеренной проблемы больших списков |
| Motion / Floating UI | Peer-диапазоны допускают React 19 | CSS и native controls достаточны; добавить лишь для подтверждённого сценария |
| Mantine / Ant Design / Carbon | Альтернативные целые системы, а не обязательные дополнения | Не смешивать с существующей; стоимость миграции сейчас не оправдана |
| Tremor | `@tremor/react@3.18.7` требует React ^18; сайт предлагает иной copy/paste подход | npm-пакет не совместим с текущим React по заявленному peer; не использовать --force/legacy-peer-deps |
| Storybook | Полезен при общем каталоге компонентов; нужен конкретный Next adapter | Отложить до выделения primitives; metadata storybook core не доказывает Next adapter |
| Lucide | Уже установлен, ISC; React 19 в peer-диапазоне | Сохранить одну систему иконок |
| React Bits / Magic UI / Aceternity | Декоративные компоненты; лицензия зависит от конкретного пакета/Pro-ассета | Не устанавливать, пока нет функционального основания; не считать весь каталог свободным |
| Playwright MCP | Apache-2.0, Node >=18; отдельный интерактивный сервер | Сейчас существующий Playwright Test покрывает нужный автоматический сценарий; MCP не устанавливался |
| Chrome DevTools MCP | Apache-2.0, Node совместим; Windows-конфигурация в официальном README | Отложить до профилирования/интерактивной отладки; не менять пользовательский browser profile |
| Figma MCP/plugin | Нужны подключение аккаунта/доступ к файлу и соответствующие функции | Не подключён; доступность сервисных страниц не доказывает доступ к макетам |
| Lighthouse | Профилирование до/после в будущем; лабораторная оценка | Не устанавливался, performance score не заявляется |

Полные версии, engines, peers и заявленные лицензии 18 npm-пакетов: [metadata](../outputs/ui-quality/package-compatibility.json). По неустановленным пакетам это проверка контрактов поставщика, не интеграционный эксперимент. Официальные URL, изменения адресов и ограничения — [реестр](ui-references.md).

## Последствия

Нет миграции UI, второго кита, внешнего платного сервиса или новых фоновых MCP. Доступность проверяется воспроизводимо без пользовательской браузерной сессии. Сложные widgets пока остаются задачей отдельного выбора; тесты и скриншоты не гарантируют удобство для реальных пользователей. При последующем внедрении сначала эталонный `/projects`, затем масштабирование.
