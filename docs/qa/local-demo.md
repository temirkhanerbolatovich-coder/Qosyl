## Исправления служебных скриптов при проверке

Первый pg_dump отказал из-за пустого `PGSERVICEFILE`: теперь libpq-переменные удаляются из унаследованного окружения, затем выставляются собственные. Первый pg_restore не получил явный `--dbname`: исправлен обязательный выбор новой временной БД. CMD с UTF-8/LF некорректно читался Windows shell: launcher переведен в ASCII/CRLF. Итоговые положительные проверки выполнены после исправлений; неуспешные попытки не считались готовностью.
