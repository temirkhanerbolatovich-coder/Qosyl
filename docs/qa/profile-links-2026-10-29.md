# Персональные ссылки профиля

Продолжение фазы 1, 29.10.2026. До шести необязательных ссылок: личный сайт, LinkedIn, GitHub, Behance, Dribbble, другая работа. У каждой подпись и отдельное разрешение публикации, по умолчанию выключенное. Для показа нужна также общая публичность профиля. Сервер фильтрует ссылки и на гостевой странице, и в выдаче откликов заказчика. Ссылка не подтверждает квалификацию.

Используется общая HTTPS-проверка прежних внешних работ; локальные имена, IP literals, логин/пароль и небезопасные схемы запрещены. Для именованных сервисов домен должен соответствовать сервису. Домен виден рядом с подписью, открытие использует noopener noreferrer. Содержимое не скачивается сервером; DNS и внешние редиректы не проверяются. Для будущего server-side fetch потребуется отдельная SSRF-защита.

POST `/api/profile` принимает необязательный profileLinks: массив {service, label, url, isPublic}. Лимит 6, label 80 символов, url 2000; общий лимит запроса остаётся 16 КиБ. Отсутствующее поле не изменяет значение, [] очищает список. Владелец сохраняет массив в прежней транзакции с аудитом. Хранение JSONB внутри StudentProfile подходит небольшому списку без внешних ссылок на элементы. Новый столбец имеет default []; таблицы и зависимости не добавлены. Старые внешние кейсы не перенесены и не потеряны.

Миграция `20261029030000_profile_links` проверена на непустой одноразовой БД с сохранностью прежних данных и откатом столбца. Затем проверено восстановление backup `.local/backups/2026-10-29T01-30-07.269Z-7c0562` (40 таблиц), и миграция применена локально. Для отката кода можно оставить аддитивный столбец; перед удалением экспортировать новые ссылки в защищённую копию.

Проверки: 494 unit-теста, production build, typecheck, ESLint новых модулей и затронутых API-файлов. Реальный E2E profile-details прошёл: ссылка сохраняется, закрытый URL отсутствует в HTML гостя, после разрешения виден и имеет безопасный rel. Полный E2E не повторялся. UI проверяется штатным profile-headline.spec.ts с заполненной ссылкой на 7 ширинах в обеих темах; результаты в `.local/ui-quality/enforced/`.

Остаются аватар и отдельная видимость остальных полей профиля, затем расширение портфолио, советы, PDF и мастер ТЗ. Данные сохраняются вручную общей кнопкой профиля; автоматического сохранения нет. Редакторская проверка KK и полная визуальная приёмка остаются открытыми.

Итог UI-запуска: 14/14, без serious/critical axe и overflow; остаётся неблокирующее замечание region. Снимки собраны, отдельный ручной просмотр нового редактора в этом этапе не выполнен.
