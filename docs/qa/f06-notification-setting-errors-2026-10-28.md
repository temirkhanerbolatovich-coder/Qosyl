# F06: ошибки настройки языка уведомлений

Отдельный обработчик различает недоступную загрузку, неподтверждённое сохранение и ответ 401 с переходом ко входу. При неопределённом результате записи предлагается обновить страницу и проверить значение до повторной попытки; не утверждается, что запись точно не произошла. Переключение интерфейса переводит видимое состояние без нового запроса и сохраняет черновой выбор. Произвольные технические детали сервера не показываются. Права, API и хранимые значения не менялись. Казахский текст требует редакторской проверки.

Проверено 451 unit-тест, typecheck, lint, api:check, production build и три целевых браузерных сценария на изолированной БД: синтетические 503/401 для загрузки и сохранения, язык/черновик/отсутствие повторов и существующий реальный сценарий настройки адресата. Полный E2E, внешняя доставка и реальные отказы инфраструктуры не проверялись. Основная БД не изменялась; предыдущая сборка сохранена в `.local/previous-build-notification-setting-errors`.
