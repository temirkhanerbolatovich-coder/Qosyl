# F06: специальные правила валидации

Клиентский `kazakhValidationMessage` расширен точными парами «путь + полная причина» из существующих схем. Добавлены правила будущего срока и города для очной работы, в том числе `project.dueAt`/`project.city` внутри передачи лида; HTTPS; закрытых вложений и количества результатов; объекта жалобы; актуальности источников/публикаций/лидов; домена ленты; даты/содержания расхода; даты и диапазона бюджета каталога; обязательного подтверждения создания черновика из передачи. Для элементов `links`/`publicLinks` сохраняется понятный номер, начиная с 1. Нельзя переводить ту же фразу на произвольном пути.

В общий словарь добавлены две ветви выбора действующего администратора/заказчика из серверного `eligibleUser`. Проверены существующие причины ролей, согласий и модерации. Серверные ограничения, API, статусы, payload, права и хранимые тексты не менялись. Новых зависимостей и архитектурных решений нет.

Сохраняются ограничения обработчика: не более 4000 символов, 30 частей, известные пути/точные форматы. Если хотя бы одна часть неизвестна, весь ответ остаётся в оригинале с существующей пометкой в KK. Комментарии модератора, проекты и история не передаются в переводчик ошибок. Новые изменения касаются только отображения.

## Проверки

- 27 новых unit-проверок используют реальные Zod-схемы и формат существующего API; вместе с прежними проверками — **483/483**, 43 файла. Проверены и смешанные известные/неизвестные причины, границы входа, индексы, неизвестный путь и текст, похожий на системную ошибку. В первой версии тестового форматирования `filter(Boolean)` терял индекс `0`; исправлен только тестовый helper, затем все случаи повторены.
- Typecheck, ESLint и `api:check` прошли. Публичный контракт не изменён. Postman CLI отсутствует; использованы текущие контракты и тестовый стек проекта без внешнего workspace.
- Браузерные проверки используют изолированную БД: реальные HTTP 400 для прошедшей даты, очной работы без города, HTTPS, срока лида и неверного ответственного. Для проверки серверного правила в тестовом DOM снимается только native `min` даты; в проверке роли добавляется поддельная option со студентом. В приложении эти ограничения не ослабляются. Все команды должны быть отвергнуты, создание записи не ожидается.
- Реальные ответы API для закрытой ссылки портфолио, неподтверждённой передачи с прошедшим сроком и диапазона бюджета дополнительно воспроизводятся в общем `LoadState`. Это проверяет общий renderer, а не прохождение всей передачи через UI. В отдельном тесте только ответ чтения карточки дополняется синтетическим комментарием модератора, совпадающим с известной ошибкой: исходный текст остаётся RU/`lang=und` при переключении интерфейса.
- Ввод сохраняется, смена языка не отправляет команду повторно. Состояние ошибки реестра проверяется на 375/768/1440/1920 px: переполнение, serious/critical axe внутри `main`, снимки `.local/f06-special-rules/`.

Первый целевой браузерный прогон остановился на native-валидации обязательного контакта: поле отсутствовало в подготовке теста. Фикстура дополнена синтетическим контактом; production-правила не менялись. Повторный целевой dev-прогон: **4/4**. Production build, Prettier и `git diff --check` прошли. Общий production-прогон: **77/77 за 5,6 минуты**, на новой управляемой изолированной БД, без retries и пропусков. Он включает четыре новых сценария и все прежние рабочие процессы. Снимки состояния ошибки просмотрены на четырёх ширинах и повторены на production-сборке; на первоначальных dev-снимках был виден штатный индикатор Next.js. Снимки являются наблюдениями, не утверждёнными эталонами дизайна.

## Границы

Это конечный пакет специальных правил, а не полная локализация Zod или F06. Общие форматы URL/ISO date, типы/дробные числа, другие поля и вложенные массивы остаются следующим пакетом. HTTPS внешних работ профиля и авторизационные причины согласия/приостановки относятся к отдельным обработчикам профиля/auth; они не становятся автоматически переведёнными от изменения общего renderer. Пользовательская причина блокировки не должна переводиться по совпадению слов.

Нативные сообщения браузера зависят от языка браузера; языковая редактура KK носителем, диктор, native zoom и приёмка разных браузеров остаются открытыми. Полный строгий `test:ui` в этом пакете не запускается. Основная база и фоновые процессы её данных этому пакету не требуются.

Локальное приложение пересобрано и возвращено на порт 3000 как web-only; health HTTP 200. Предыдущая сборка сохранена в `.local/previous-build-f06-special-rules`. Миграций и изменений основной БД нет, отдельные фоновые процессы её данных не запускались.
