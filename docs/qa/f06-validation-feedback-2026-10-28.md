# F06: типовые ошибки валидации

Клиент переводит распознанные составные сообщения Zod о минимальной/максимальной длине строки, целочисленных пределах и отсутствующих значениях для явно перечисленных полей. Числа сохраняются. Любая неизвестная часть, поле или формат оставляет исходное сообщение целиком; пользовательские и динамические данные не угадываются. API, глобальный язык Zod и правила валидации не меняются. Ошибки массивов, enum и других форматов остаются исходными. Перевод нуждается в редакторской проверке носителем языка.

Проверены 446 unit-тестов, typecheck, lint, api:check, production-сборка и целевой браузерный сценарий с синтетическим 409 на изолированной БД: распознанное сообщение переводится, неизвестное остаётся исходным. Полный E2E, живой запрос с Zod и визуальная приёмка всех форм не выполнялись. Локальный веб-сервер восстановлен; предыдущая сборка сохранена в `.local/previous-build-validation-feedback`. База приложения не изменялась.
