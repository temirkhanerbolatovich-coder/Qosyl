## Оставшиеся ограничения

Галерея изображений не добавлена; ссылки не загружаются сервером. Ручной порядок — внутри самостоятельных кейсов, подтверждённые проекты отдельно по времени. Нет PDF/советов/мастера ТЗ. Старые подтверждённые записи без связи с назначенным исполнителем или события приёмки не получают platform_verified в новой выдаче; данные и согласия не исправляются автоматически. Частные кейсы фильтруются в API откликов серверным запросом; отдельный браузерный сценарий такого скрытия в карточке кандидата в этом этапе не запускался. См. правила безопасного отката в документе функции.
