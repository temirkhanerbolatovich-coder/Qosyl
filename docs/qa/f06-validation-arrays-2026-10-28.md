# F06: списки и варианты валидации

Добавлены типовые ограничения размера известных массивов и пути вида `поле.индекс` для элементов; номер для пользователя начинается с единицы. Точные наборы category, mode и difficulty показывают предложение выбрать допустимый вариант. Учитываются русские формы слова «символ» и «элемент». Неизвестное поле, вложенный путь, неизвестный набор или формулировка оставляют исходное составное сообщение целиком. API, серверная валидация и глобальная локаль не менялись; редактура казахского носителем языка остаётся необходимой.

Проверены 448 unit-тестов, включая реальные ошибки Zod для всех трёх enum, размера списка и индексированного элемента; typecheck, lint, api:check, production build и целевой браузерный сценарий на изолированной БД. Сценарий воспроизводит синтетические ошибки и неизвестный текст, а не реальную серверную отправку каждой формы. Полный E2E и полная визуальная приёмка не запускались. Основная база не менялась; предыдущая сборка сохранена в `.local/previous-build-validation-arrays`.
