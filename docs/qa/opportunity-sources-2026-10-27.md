# F02: источники и качество поиска — 27.10.2026

## Выполненный пакет F02a

Единый реестр scripts/opportunity-sources.ts используется сборщиком и новым read-only аудитом npm run opportunities:audit. Аудит использует тот же HTTPS-загрузчик и парсер; не обращается к БД, не меняет расписание и ничего не публикует. Ошибка источника даёт ненулевой exit code после сохранения остальных результатов. Повтор разбора одного ответа сравнивается отдельно от сетевого запроса и дедупликации БД.

Добавлены четыре проверенных источника: RSS Saginov Technical University, RSS Академии искусств Жургенова, HTML MNU, статьи Astana Hub. Новых зависимостей, таблиц и API-контрактов нет.

Исправления: ссылки на профили авторов Astana Hub исключены; нейтральная статья больше не становится мероприятием; казахские итоги/награждения/прошедшие события классифицируются как новости. Расширены RU/KZ/EN термины направлений. Слово «сервис» и общее «қызмет» исключены из туризма, чтобы не выдавать веб-сервисы за туристические возможности. Эти эвристики требуют редакторской проверки.

## Проверки

- 322 unit-теста, включая 5 новых регрессий парсера/категорий.
- 30 интеграционных тестов на отдельной временной БД: HTTPS-защита, сбор, повторы, редакционные версии, публикация и поиск. Существующий сценарий расширен казахским поиском права, туристической практикой и исключением веб-сервиса; pending не виден в публичной выдаче.
- TypeScript, lint, production build; проверка неизменности OpenAPI отдельно записана в локальный лог.
- Postman CLI отсутствует. Проверки реального TLS транспорта выполнены существующим проектным harness; они не называются Postman Simulation.
- Браузерный E2E в этом пакете не запускался: UI не изменён. Изменение серверного поиска проверено интеграционно.

Локальные доказательства (исключены из Git): outputs/opportunities/source-audit.json, f02-first-collection.json, f02-repeat-collection.json; .local/f02-*.log. Публичный отчёт содержит сводку, а не персональные данные или секреты.

## Что ещё требуется для полного F02

1. Повысить долю настоящих открытых возможностей, особенно медицины, туризма, права и творческих направлений; количество новостей не считать покрытием.
2. Извлекать условия/дедлайны из отдельных страниц с сохранением исходного текста, часового пояса и неизвестных значений. Это отдельный ограниченный проход, не неограниченный crawler.
3. Дополнить покрытие регионов: центральный Astana Hub не означает подключение всех региональных филиалов.
4. Gov.kz пока возвращает неподдерживаемую JS-оболочку. Satbayev в этой среде дал FEED_NETWORK_ERROR; EKTU превысил лимит 1 MiB; ToU не распознан. Защита не ослаблялась; эти кандидаты не включены как рабочие.
5. Дедупликация разных URL между источниками и поисковые варианты написания остаются отдельными задачами. Нынешняя дедупликация по каноническому URL внутри источника не заменяет их.
