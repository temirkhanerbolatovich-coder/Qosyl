# Профиль: курс, языки и опыт

29.10.2026, продолжение фазы 1. В существующую форму добавлены необязательные курс (1–8), языки (10 по 60 символов) и до пяти записей опыта. Типы: работа, учебный, личный, волонтёрский проект. Поля: организация/проект, роль, период YYYY-MM, занятость, задачи/вклад и результат (по 500 символов). Пустое окончание означает продолжается. Опыт не требуется для отклика; сведения не подтверждаются автоматически.

Каждая новая запись закрыта по умолчанию. Публичный профиль и список откликов заказчика используют единое серверное правило: общая публичность профиля и явная публичность записи. В клиент публичной страницы передаются только разрешённые записи. Владелец видит все записи через `/api/profile`. Запись имеет ярлык «Добавлено пользователем». Доступ к редактированию остаётся через self-profile session и транзакционную проверку аккаунта. Поля запроса strict; userId и признаки verified не принимаются.

## Хранение и API

Миграция `20261029020000_student_details`: три аддитивных столбца в StudentProfile, без новых таблиц. JSONB уместен для небольшого списка без внешних ссылок на элементы; при появлении отдельных операций, связей или поиска опыта модель нужно пересмотреть. Порядок — порядок массива; сохранение заменяет весь массив. Параллельные редакторы пока имеют прежнюю семантику последнего сохранения.

POST `/api/profile` принимает необязательные studyYear, languages, experiences. Отсутствующие поля остаются неизменными; null очищает курс, [] очищает список. experiences содержит organisation, role, kind (employment/academic/volunteer/personal), employment, startMonth, endMonth, tasks, results, isPublic. Окончание не раньше начала; серверные межполевые проверки не полностью выражаются OpenAPI. Прежний лимит тела 16 КиБ сохраняется: длинные коллекции внешних работ и опыта могут потребовать сокращения текста. Ошибка показывается существующим механизмом.

Тест миграций применяет прежнюю схему в одноразовой БД, добавляет синтетический профиль, проверяет сохранность всех старых полей, defaults и откат новых столбцов. Перед локальным применением создана копия `.local/backups/2026-10-29T01-14-36.143Z-35ec8b`; восстановление подтвердило совпадение всех 40 таблиц. Миграция применена без reset и seed основной БД. Откат: сохранить экспорт новых данных и вернуть прежний код; аддитивные поля можно оставить. Удалять поля только после экспорта.
