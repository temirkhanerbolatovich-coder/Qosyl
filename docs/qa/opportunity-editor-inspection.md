# Проверка исходной страницы в редакторе — F02c

27.10.2026. В редакционной карточке добавлена кнопка «Проверить сроки и условия на сайте». Команда inspectContentPage входит в существующий POST /api/admin/content и описана в OpenAPI. Результат появляется в раскрываемом журнале «Последние решения и изменения»; отдельно записываются запрос, результат или ошибка загрузки.

## Границы

Используется существующий append-only ContentAudit: запись содержит администратора, дату, ID исходной редакции, URL, календарные даты с исходными фрагментами и ограничения участия. Новая таблица не нужна: сведения предназначены для чтения редактором, а не автоматического расчёта доступности. Редакция, updatedAt материала, ручной текст, дедлайн карточки и статус публикации не изменяются. При изменении редакции старые проверки остаются в истории и не считаются проверкой новой версии.

Команда проверяет актуальные права и состояние администратора, подтверждение email вне localMode, включение модуля/источника и optimistic concurrency. URL берётся из сохранённой редакции, не из произвольного запроса. Применяется защищённый HTTPS-загрузчик. Одна проверка в минуту на администратора или материал; резервирование выполняется под существующей блокировкой настроек перед сетью. HTTP-запрос выполняется вне SQL-транзакции. GET не обращается к источнику.

Ошибка загрузки записывается в журнал кодом без внутренней трассировки. Неожиданный сбой процесса может оставить только запись запроса; отсутствие завершения не означает успешную проверку. История показывает последние 50 действий; более старые записи сохраняются в БД. Автоматической актуализации, публичного отображения доказательств или гарантии права участия нет.

## Проверки

- 341 unit-тест, lint, TypeScript, production build.
- 30 интеграционных тестов: дополнительно проверены запрет студенту, устаревшая версия, сохранность редакции и статуса, привязка доказательства, частотный лимит, ошибка FEED_TIMEOUT.
- Целевой браузерный сценарий редактора прошёл: публикация, история, повторная проверка/отзыв; новая кнопка видна, переполнения нет при 375/768/1440/1920 px. Это не проверка фактического клика по новой сетевой команде в браузере: её серверный путь проверен интеграционно с управляемым fetcher. Живой загрузчик и извлечение проверялись отдельно на F02b.
- Первый браузерный прогон использовал старую сборку; после rebuild прошёл. Первоначальный контрактный тест ожидал семь команд и обновлён до восьми. Пробная попытка изменить время тестового audit была отклонена append-only триггером; финальный тест использует отдельные сущности без изменения истории.
- Полный E2E и screen reader в этом пакете не запускались. Postman CLI отсутствует; проектные проверки не называются Postman Simulation.

Локальные логи: .local/f02c-*.log; снимки: test-results/**/inspection-editor-*.png. Следующий этап F02 — актуальность и покрытие открытых возможностей по направлениям; F03 требует редакторских решений, которые не выполняются автоматически.
