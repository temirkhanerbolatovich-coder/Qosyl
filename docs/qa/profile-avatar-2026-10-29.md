# Проверка безопасного аватара — 29.10.2026

Область: редактор `/student/profile`, публичный `/talent/{id}`, собственные команды `/api/profile/avatar`, выдача `/api/avatars/{userId}`. [Правила и ограничения](../profile-avatar.md), [решение](../../11_Reports/Decisions/ADR-017-profile-avatar.md).

## Проверки

- `npm test`: 505 тестов, 48 файлов. В том числе 5 тестов реального декодера и 4 HTTP-boundary теста: EXIF/добавленные байты, PNG/JPEG, пиксельный лимит, APNG, неверный MIME/сигнатура, пустой/большой/повреждённый файл, origin/session/подмена полей, поток без достоверного Content-Length.
- `npx playwright test tests/e2e/avatar.spec.ts tests/e2e/profile-headline.spec.ts tests/e2e/profile-details.spec.ts tests/e2e/profile-visibility.spec.ts`: 6/6. Реальные PostgreSQL и HTTP, загрузка через UI, повторная загрузка страницы, декодирование JPEG, приватность, отдельная публикация, конфликт revision, замена со сбросом согласия, отзыв, удаление и fallback; лимит неуспешных попыток; скрытие профиля и блокировка аккаунта. Прежние расширенные поля сохраняются.
- `npx playwright test tests/e2e/workflow.spec.ts`: 22/22, основной жизненный цикл маркетплейса, роли, модерация, согласования, сдача, оплата, портфолио, регистрация и уведомления.
- Первый объединённый запуск этих наборов: 15 passed, 1 failed, 12 skipped. Новые регистрации исчерпали общий auth rate-limit до регистрации workflow (в UI подтверждён 429). Повторные отдельные прогоны выше прошли. Лимит приложения не ослаблялся. Для воспроизведения запускать группы отдельными командами с новой изолированной БД; полная композиция всех E2E остаётся ограничением тестового окружения.
- `npm run test:attachments`: 15/15, включая реальный потоковый reader. Дополнительно backup/restore 51 вложения, 7 связей, 104858346 байт с совпавшим SHA256. Общий reader сохранён совместимым с приватными вложениями.
- `npm run test:profile:migration`: непустая одноразовая БД, сохранность прежних данных, default private, ограничение размера в SQL и rollback новой таблицы.
- Production build/TypeScript, ESLint затронутых файлов и `npm run api:check` прошли. При закреплении sharp npm сообщил 0 известных уязвимостей; это не полноценный аудит безопасности.

## UI Quality

`npm run test:ui -- avatar.spec.ts`: 14/14 — 320/375/390/768/1024/1440/1920 px, light/dark. Реальное изображение, клавиатурный переход к публикации, неверный файл, сохранность предыдущего фото, отсутствие overflow и serious/critical axe. Артефакты: `.local/ui-quality/enforced/results/avatar-*/avatar.png` и вложенный avatar-audit. Снимки просмотрены на 375/768/1440/1920; отдельные фрагменты `.local/avatar-review-*.png`. Тестовое фото — синтетический одноцветный PNG, не реальный человек. На 375 в снимке видна сфокусированная skip-link, это состояние клавиатурного теста.

Это не полная WCAG/UX-приёмка. Остаётся прежнее неблокирующее axe region; отдельная визуальная приёмка KK, 200% zoom, screen reader и всех сетевых/loading состояний не выполнена. Safari/Firefox и production email-verification режим в этом этапе не проверялись.

## Локальные данные

До миграции создана и восстановлена в отдельную БД копия `.local/backups/2026-10-29T01-53-32.478Z-8fe1ea`: 40 таблиц, совпали SHA256 и числа строк. После этого применена только ожидавшая миграция 20261029050000_profile_avatar; без reset/seed. Новая таблица не переписывает данные профилей. Откат и ограничения хранения описаны в документе функции. Внешнее развёртывание не выполнялось.

Открытые пункты общего ТЗ: самостоятельные кейсы портфолио, советы, PDF-резюме, мастер ТЗ и финальная интеграционная приёмка. Задача безопасного аватара не означает завершение всего расширения.
