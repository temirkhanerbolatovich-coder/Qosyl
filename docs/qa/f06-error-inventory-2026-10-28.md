# F06: инвентаризация ошибок и Threads

Выполнена [сверка обработчиков](../localization-error-inventory.md). В общий словарь добавлены 57 фиксированных сообщений: проверка файлов и формата запроса, ограничения публикации и лидов, портфолио, модерация, затраты и Threads. Всего `moduleErrorsKk` содержит 106 строк. Число словарных строк не является оценкой полноты локализации; динамические/специальные ошибки и другие механизмы перечислены в инвентаризации.

В Threads причина HTTP-отказа проверки подключения сохраняется для показа; сетевой отказ получает понятное сообщение. Некорректные JSON или схемы ответа дают фиксированное сообщение и не раскрывают сырой Zod. Проверка подключения не включает поиск при ошибке схемы. Уже видимая ошибка меняет язык без нового запроса, поле поиска сохраняется. Неизвестный безопасный ответ своего API остаётся исходным с пометкой. Серверный API и ограничения Meta не изменялись; реальный доступ к чужим публикациям этим этапом не подтверждается.

Проверено: 451 unit-тест, typecheck, ESLint, api:check, Prettier и production build. Три целевых браузерных теста на dev-сервере и изолированной БД проверили отказ доступа, ошибку схемы статуса, лимит/доступ/ошибку схемы поиска/неизвестный ответ и сетевой отказ; обращения Threads перехвачены в тестовом браузере, запросы провайдеру не отправлялись. Первый тестовый прогон не открыл вкладку лидов и не нашёл панель; подготовка исправлена, все три сценария повторены успешно. В четырёх состояниях 375/768/1440/1920 px нет горизонтального переполнения и serious/critical axe-нарушений в покрытой области; просмотрены снимки 375 и 1440. Снимки тестов являются наблюдениями, не эталонами дизайна.

Локальное приложение пересобрано и возвращено на порт 3000; основной базе не требовались изменения. Предыдущая сборка сохранена в `.local/previous-build-f06-error-inventory`. Фоновые процессы отдельно не запускались. Человеческая редактура казахского и расширенная UX-приёмка остаются открытыми.

Финальная проверка: общий `npm run test:e2e` прошёл **66/66 за 5,0 минут** на той же production-сборке с новой изолированной тестовой базой; повторы/пропуски не использовались. Это включает три новых сценария Threads и существующие рабочие процессы. Полный строгий `test:ui` этим пакетом не повторялся: новые error-состояния проверены четырьмя axe/layout срезами внутри целевого сценария, а другие покрытые состояния — общим E2E. Снимки Threads дополнительно сохранены в `.local/f06-threads-errors/`.
