# F06: ошибки файлов, редактора и передачи запросов

Общий словарь `MarketplaceMessage` дополнен 45 точными фиксированными формулировками о доступе к файлам, квотах, редакторской проверке, передаче запросов и общих ошибках. Условия участия двух сторон и другие ограничения сохранены. Неизвестные и динамические сообщения остаются исходными; механизмы других компонентов автоматически не считаются покрытыми. Серверные API, статусы и правила не менялись. Переводы требуют проверки носителем казахского языка.

Проверены 449 unit-тестов, typecheck, lint, api:check и production build. Целевой браузерный сценарий на изолированной БД использует синтетические ошибки общего компонента и проверяет перевод ограничений файла и публикации, а также исходное неизвестное сообщение. Реальные ошибки всех соответствующих API и полный E2E в этом пакете не проверялись. База приложения не изменялась; предыдущая сборка сохранена в `.local/previous-build-module-errors`.
