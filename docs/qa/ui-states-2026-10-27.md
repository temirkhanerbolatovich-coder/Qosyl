# Проверка состояний интерфейса 27.10.2026

Продолжение внедрения дизайн-системы. Изменения ограничены components/opportunities.tsx и components/site-header.tsx; API, backend, права и редакционные правила не менялись. Новые зависимости не добавлялись.

## Найденные и исправленные проблемы

Возможности раньше показывали сообщение «материалов пока нет» ещё до завершения первого запроса. Добавлено отдельное состояние загрузки с role=status, ошибкой role=alert и подтверждённым пустым результатом после успешного ответа. При сбое появилась явная кнопка повторной загрузки; введённые поля формы не сбрасываются. Pagination заблокирована во время запроса. Повторная отправка того же query запускает новый запрос, а не оставляет интерфейс в ожидании без изменения effect dependencies.

Защита от устаревшего ответа, локальная проверка expiresAt и существующие 15-секундный polling/проверка при focus сохранены. На главной пустой или недоступный второстепенный блок по-прежнему скрывается. Отказ не превращается в успешную выдачу, материалы pending_review не публикуются.

У мобильной навигации есть aria-controls; Escape из её элементов закрывает меню и возвращает focus на инициирующую кнопку. Native select темы и навигационные ссылки сохраняют исходное поведение.

## Воспроизведение

```powershell
npx playwright test --config=playwright.ui.config.ts states.spec.ts --reporter=list --output=.local/ui-quality/states
```

Новые сценарии:

- Задержанный ответ: видна загрузка, не виден преждевременный empty state; после ответа empty state появляется. Повторная отправка того же поиска завершается.
- HTTP 503: видна ошибка и retry; после восстановления реального локального ответа ошибка снимается, введённые фильтры сохраняются.
- Фильтры каталога: раскрытие/сворачивание сохраняет ввод, применение отражается в query URL, пустая выдача сбрасывается обратно к seeded проектам.
- Клавиатура: Enter открывает mobile menu, Tab ведёт к ссылке, Escape закрывает и возвращает focus; на desktop Enter выполняет переход по настоящей ссылке.

Ширины: 320/375/390/768/1024/1440/1920, обе темы. В состояниях загрузки/пустоты/ошибки выполняются axe и проверка ширины документа. Это проектный Playwright с управляемым browser-route ответом; он не называется Postman Simulation и не доказывает отказ реального внешнего источника. Postman CLI в среде не найден; установка нового сервиса для локального UI state regression не выполнялась.

Первый прогон остановлен после обнаружения неоднозначных тестовых селекторов: глобальный role=alert включал route announcer Next.js, а menu locator искал старое имя после открытия. Селекторы ограничены областью блока и постоянной кнопкой; проверки поведения не удалялись.
