# Q24: локальная приёмка первого адаптера Threads

**Актуальное ограничение доступа.** Причина пустой выдачи установлена 26.10.2026 по официальной документации Meta: без одобрения `threads_keyword_search` поиск ограничен публикациями авторизованного пользователя. `GET /me/threads` под `gruppavtipo252` вернул HTTP 200 и `data: []`; исходный `/keyword_search` также вернул пустой массив до нормализации Qosyl. Панель Meta показывает «Готово к тестированию», а попытка добавить разрешение в App Review требует необратимого статуса Tech Provider, подтверждения компании и прав доступа. Переход не выполнен, заявка не отправлена. Владелец отказался от создания тестового поста и выбрал поиск чужих публикаций через App Review. Получение чужой публикации пока заблокировано одобрением Meta.

26.10.2026. **Подключение к живому Meta API подтверждено частично:** OAuth выполнен под `gruppavtipo252`, профиль и keyword_search вернули 200; долгосрочный токен находится в `.env`, поиск включён и проверен в панели admin. Запрос «нужен сайт» вернул 0 кандидатов, 0 отброшенных; настоящий клиент Qosyl по запросу «Threads» также вернул 0. Проверка известной публичной публикации и охвата остаётся открытой. Лиды/заказы не создавались. Фоновый мониторинг и полный Q24 не объявляются завершёнными.

## Контракт и данные

Добавлен `/api/admin/leads/threads` GET/POST и общий Zod/OpenAPI. Core RPC остаётся 30 команд/10 видов. Секрет не поступает из браузера; используется фиксированный официальный host. Статус configured означает только наличие локальной строки токена. Новых зависимостей, таблиц, миграций и seed нет. Существующие Lead/LeadEvent сохраняют прежние правила и согласие; поиск их не меняет. Счётчики запросов/пауза используют RateLimit.

Первичный контракт поиска получен из [официальной коллекции fbsamples](https://github.com/fbsamples/threads_api/blob/main/postman/threads-api.postman_collection.json), setup/OAuth — из [официального sample](https://github.com/fbsamples/threads_api) и [коллекции Meta](https://www.postman.com/meta/threads/collection/dht3nzz/threads-api). Часть страниц Meta Developers отвечала 429; Orbit search успешен, integrate 404. Реальные числовые квоты, стоимость, App Review и охват публичной выдачи на аккаунте владельца не подтверждены.
