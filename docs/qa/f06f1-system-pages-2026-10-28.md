# F06f1 — системные страницы RU/KK

28.10.2026. Первый пакет F06f: `/help`, `/terms`, `/privacy`, not-found и экран ошибки. Полный F06 и юридическая/языковая редакторская приёмка не завершены.

## Изменения

Статические тексты переведены через существующий LocaleProvider и точный словарь `system-copy.ts`, подключённый к общему механизму отображения. Компоненты реагируют на переключение языка без навигации; исходная серверная разметка сохраняет выбранную cookie-локаль. Новых зависимостей, API, миграций и действий с основной БД нет. Ключи шагов справки, маршруты ссылок и обработчик retry остаются стабильными.

Справка теперь упоминает уже реализованную сдачу закрытыми файлами наряду с HTTPS-ссылкой. В конфиденциальности исправлено повторение «В В». Условия не расширены: сохранены 18+, согласие обеих сторон, модерация, отдельные состояния приёмки/закрытия/оплаты, отсутствие escrow, гарантий оплаты и юридического арбитража. Оба языка сохраняют указание на рабочую редакцию локального пилота и необходимость утверждения документов перед публичным запуском. Это перевод текущих текстов, а не новая правовая оценка.

Экран ошибки не показывает объект ошибки, digest или внутренние сведения. Перед повтором изменений по-прежнему предлагается проверить их состояние. Смена языка сама не вызывает reset.

- Unit: 436/436, включая три новых проверки RU/KK ошибки, неразглашения внутренних данных и стабильного обработчика повтора.
- Общий E2E: 56/56 за5,5мин на финальной сборке. Отдельный набор test:ui196 не повторялся: новые страницы проверены64 состояниями, существующие сценарии — общим E2E. API не менялся; отдельный api:check в этом пакете не запускался. Локальные ссылки документации и git diff --check проверены.
- Production build, lint и typecheck успешны. Целевые E2E: 5/5 за55,2с, все64 axe/layout состояния без serious/critical нарушений и переполнения.
- `tests/e2e/system-pages-locale.spec.ts`: четыре маршрута × два языка × две темы × четыре ширины375/768/1440/1920 =64 состояния. Проверяются заголовки, lang, сохранение query/ссылок, отсутствие POST, axe serious/critical и горизонтальное переполнение.
- Отдельный сценарий без JavaScript: KK SSR условий/конфиденциальности/404, ограничения18+/файлов/антивируса, reload, реальный HTTP404 и возврат в каталог.
- Экран ошибки проверен на уровне компонента; настоящий сбой Next error boundary в браузере искусственно не вызывался. Проверка callback не означает успешное восстановление после всех серверных отказов.

Тестовый сервер использует отдельную E2E-БД. Внешних публикаций, писем и сообщений нет. Снимки находятся в `test-results/system-pages-locale-*/`, логи — `.local/f06f-*.log`. Просмотрены KK-снимки: 404 dark375, справка light768, конфиденциальность light1440, условия dark1920. На этой выборке блоки/кнопки помещаются, перекрытий не видно. Длинные снимки масштабировались при просмотре; это не проверка физического устройства или каждого пикселя. Снимки не являются утверждёнными эталонами дизайна.
