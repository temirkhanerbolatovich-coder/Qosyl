# F06c — кабинеты и рабочая область RU/KK

F06c принят локально 28.10.2026 после F06b. Полный F06 и внешний запуск остаются открытыми.

## Реализовано

- Обзор кабинета, свои отклики, проекты исполнителя и заказы клиента: подписи, сводки, пустые состояния, навигация, управление списком уведомлений.
- Рабочая область: этапы, условия и история версий, подтверждения, чек-лист, сдача/правки/приёмка, портфолио, отзывы, отдельные заявления оплаты, закрытие, спор, отмена и жалоба.
- Встроенные формы изменения условий и создания/редактирования заказа, приватные вложения и панель переданных бизнес-запросов используют выбранный язык.
- Числа/даты используют прежние locale-aware helpers; известные enum оплаты и истории получили KK-подписи без изменения значений.
- Исходные тексты заказов, уведомлений, материалов, отзывов, имён файлов и неизвестных ответов сервера не переводятся автоматически. Основные исходные блоки помечены `lang="und"`; шаблоны заданий остаются RU с явной пометкой.

## Устройство и границы изменений

`src/lib/marketplace-copy.ts` содержит явные пары RU/KK для повторяющихся статических строк. `useMarketplaceCopy` использует уже существующий LocaleProvider, не обходит DOM и не вызывает внешние сервисы. Общие ActionFeedback/LoadState переводят известные локальные сообщения при отображении: в состоянии остаётся исходный идентификатор строки. Неизвестные детали показываются без изменения и с пометкой исходного сообщения в KK.

Существующие payloads, API routes, права, условия переходов, согласия, ограничения вложений и оплаты не изменены. Язык не входит в ключи форм и запросов. Формы не перемонтируются от смены языка. Никаких миграций, seed основной БД, зависимостей или внешних отправок этот пакет не добавляет. Нового архитектурного решения, требующего ADR, нет.

## Проверяемые сценарии

`tests/e2e/marketplace-locale.spec.ts` использует только управляемую loopback E2E-БД и синтетический заказ. Реальные команды создают отдельную фикстуру через штатные роли, модерацию и выбор исполнителя. KK UI проверяет два согласия, приватную загрузку файла, сдачу, приёмку, отдельные подтверждения оплаты и закрытие. Смена RU/KK сохраняет несохранённые условия, файл в input, выбранный attachment, заметку сдачи и черновик портфолио; не отправляет повторные POST. Локальная ошибка пустой сдачи и уже видимый успех переводятся повторно.

Отдельный сценарий перехватывает запрос создания черновика: pending, неизвестная ошибка403 и сетевой отказ явно синтетические. Данные полей сравниваются до/после переключения; неизвестная деталь сохраняется, сообщения о неподтверждённых изменениях не выдают сбой за успех. Синтетический успех/реальное сохранение этой формы этим перехватом не утверждаются.

Визуальная выборка: 16 сочетаний RU/KK, light/dark и375/768/1440/1920px распределены между dashboard/editor/work, плюс завершённая работа. Это не полное декартово произведение всех экранов. Axe проверяет serious/critical и горизонтальный overflow после готовности шрифтов, title и конечных переходов.

## Первичные ошибки тестов

Первый прогон нашёл неоднозначный status после загрузки и сдачи: UI одновременно показывает несколько независимых сообщений. Селектор уточнён до сообщения команды. Тест страниц исполнителя ошибочно оставался под ролью клиента и закономерно получал403; теперь выбирается правильная роль. Выбор шаблона проверяется по доступной роли combobox. В фикстуре формы был пропущен обязательный contactPrivate; добавлен синтетический контакт и assert валидности перед отправкой. Валидация и права приложения не ослаблялись.

## Выполненные проверки (28.10.2026)

- `npm run build`, `npm run lint`, `npm run typecheck`, `npm run api:check` — успешны; контракты соответствуют валидаторам.
- `npm test` — 430/430 в35 файлах. Новые проверки: повторный перевод локальных сообщений, сохранение неизвестных деталей, полный набор enum истории/оплаты, формулировки ограничений платежей и unscanned-файлов.
- Общий `npm run test:e2e` — 44/44 за2,9 минуты, включая3 новых F06c-сценария. В тесте закрытия добавлено ожидание видимого успеха каждой стороны перед чтением результата: click не означает завершение POST. Код закрытия и доменные правила не менялись.
- Просмотрены снимки dashboard KK dark375/1920, editor KK dark768/light1440, work KK light375 и RU light1440. На просмотренных снимках нет перекрытия основных блоков и действий. Автоматический axe/overflow охватывает17 новых состояний. Нативный file picker остаётся на языке браузера.

- Строгий `npm run test:ui` — 196/196 за 3,5 минуты; 168 состояний с axe-аудитом, без serious/critical нарушений и горизонтального overflow, без пропусков и flaky-тестов.

## Оставшееся

Публичная карточка заказа, список кандидатов/выбор исполнителя, публичное портфолио, admin, справка, юридические тексты, содержимое шаблонов, серверные уведомления и письма ещё не полностью переведены. Следующий пакет F06d — публичная карточка заказа, кандидаты и публичное портфолио; затем оставшиеся административные и системные тексты.

Native file picker/validation зависят от браузера. Проверка носителем казахского, диктор, настоящие устройства, Firefox/Safari, native zoom и производительность остаются отдельной приёмкой. Платформа не проводит платежи; файлы по-прежнему unscanned. Реальные получатели/SMTP/доставка сообщений не проверялись.

Логи `.local/f06c-*.log`, PNG и приватные traces в `test-results/`, UI-проверки в `.local/ui-quality/enforced/`; они игнорируются Git. В отчёт не включаются cookies, пароли, приватные ссылки и адреса аккаунтов.
