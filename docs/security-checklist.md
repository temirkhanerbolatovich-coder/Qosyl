# Проверки безопасности и границы пилота

Этот документ описывает реализованные меры и ограничения. Он не является заключением внешнего аудита. Фактически выполненные проверки и результаты находятся в `docs/qa-report.md`.

| Область         | Реализация / проверяемое правило                                                                                                                                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Пароли и сессии | Better Auth, хеширование библиотекой, httpOnly SameSite=Lax cookie; secure cookie при HTTPS; срок сессии 7 дней; cookie-cache отключен.                                                                                                                          |
| Почта           | Для публичного режима требуется подтверждение email. Без SMTP разрешен только явный loopback local mode; reset-письма — в игнорируемой локальной папке, HTTP-почтового ящика нет.                                                                                |
| Восстановление  | Срок reset-токена 30 минут, одноразовость и отзыв прежних сессий после смены пароля; без вывода токенов в журнал.                                                                                                                                                |
| Перебор         | Better Auth использует DB-backed лимиты: signup6/min, signin10/min, reset-request4/min. Лимиты привязаны к поддерживаемому библиотекой идентификатору запроса; доверенные прокси требуют отдельной проверки перед хостингом.                                     |
| Рабочие роли    | Только student/client через валидируемый профиль. Admin назначается серверной командой или локальным seed. URL/query/body не дает административных прав.                                                                                                         |
| Блокировка      | Актуальный status/roles читаются из PostgreSQL; блокировка удаляет сессии и фиксирует причину. Админ не может заблокировать себя/другого admin через обычный endpoint.                                                                                           |
| IDOR            | Серверные role + ownership + state guards. Только автор видит отклики на свой заказ; только участники видят рабочую область.                                                                                                                                     |
| Гонки           | Сериализуемые транзакции, уникальный отклик project/student, уникальная версия project/number, уникальный отзыв project/author. Конфликт возвращается как409, назначение второго исполнителя отклоняется.                                                        |
| CSRF            | Better Auth проверяет trustedOrigins. Собственные POST endpoints требуют точный Origin и JSON; cookie SameSite=Lax дополнительно ограничивает отправку. GET не изменяет бизнес-состояние.                                                                        |
| XSS             | Пользовательский текст рендерится React как текст; произвольный HTML не исполняется. Ссылки только HTTPS без userinfo; внешние ссылки используют noopener/noreferrer.                                                                                            |
| SQL injection   | Prisma с параметризованными запросами; строки фильтров не собирают SQL.                                                                                                                                                                                          |
| Размеры         | Platform JSON до64KiB, профиль до16KiB; длины/массивы/суммы/даты ограничены Zod на сервере. До5 ссылок на сдачу/отклик; бинарные загрузки отсутствуют.                                                                                                           |
| Спам            | DB-backed лимиты платформенных изменений, откликов и жалоб; отклики бесплатны.                                                                                                                                                                                   |
| Приватность     | Публичные select-проекции не включают контакты, точную локацию, приватные сдачи, сессии и учетные записи. Портфолио публично только после согласий обеих сторон на текущее содержание и публичного профиля исполнителя.                                          |
| Аудит           | Существенные изменения, автор и время хранятся в PostgreSQL; API редактирования/удаления истории отсутствует. Администратор базы сохраняет техническую возможность изменения: ограничение БД-прав и внешний immutable audit — отдельная эксплуатационная задача. |
| Заголовки       | CSP, nosniff, frame-ancestors none/X-Frame-Options DENY, Referrer-Policy, запрет camera/microphone/geolocation; HSTS вне local mode.                                                                                                                             |
| Секреты         | `.env`, `.local`, письма и demo-credentials исключены из Git. Примеры конфигурации не содержат реальных паролей.                                                                                                                                                 |
| Демонстрации    | Явный demo flag, Oxford Team без публичных откликов. Публичный режим не включает demo выдачу. Нет реальных данных CRM или участников опроса.                                                                                                                     |

## Осознанные ограничения

PostgreSQL дополнительно запрещает UPDATE/DELETE событий, записей модерации, сдач, правок и отзывов триггерами. Условия соглашения и записанные подтверждения также неизменяемы. Технический владелец БД может отключить триггеры; отдельная роль приложения без DDL, резервные копии и внешний аудит требуются при размещении. Локальный кластер предназначен только для демонстрации.

- CSP разрешает inline script/style для совместимости с текущим Next.js App Router. Это не nonce-based строгая CSP. Политика снижает часть рисков, но не заменяет корректный рендеринг и валидацию. Перед публичным запуском рассмотреть nonce и провести регрессию hydration.
- Вложения в P0 — ссылки, а не закрытое файловое хранилище с антивирусом. Пользователь контролирует внешнюю страницу; платформа не подтверждает ее содержимое и не скачивает URL сервером.
- Реальная доставка SMTP, WAF/proxy IP semantics, DDoS-устойчивость, восстановление резервных копий и внешний pentest локальной проверкой не подтверждаются.
- Оплата вне площадки. Заявления участников не являются платежным документом, гарантией, escrow или независимым подтверждением банковской операции.
- Юридические тексты требуют проверки для реального пилота в Казахстане. Несовершеннолетние и высокорисковые услуги в начальный пилот не включаются.
