# Q11: актуальность и напоминания

Worker: npm run worker:lifecycle:once или npm run worker:lifecycle. npm start и START_DEMO запускают web и worker под общим supervisor. Просмотр HTTP никогда не запускает обработку. PROJECT_LIFECYCLE_ENABLED=false отключает worker; interval60сек, batch50 (параметры PROJECT_LIFECYCLE_INTERVAL_MS и PROJECT_LIFECYCLE_BATCH_SIZE). Режим локального компьютера не работает во время выключения.

Истечение: только опубликованный реальный заказ без исполнителя с dueAt<=now, активные отклики закрываются, история и системное событие actor=null сохраняются. Напоминания: автору за24ч до окончания публикации; исполнителю по последней двусторонне согласованной версии (включая пропущенный срок после простоя); заказчику через48ч после последней сдачи. Завершённые/отменённые/спорные задания не напоминаются. Только внутренние уведомления, без внешней почты.

Постоянный уникальный ключ сохраняется после прочтения; автоматические уведомления не удаляются/не переписываются. Одна Serializable-транзакция, advisory lock, row locks и не более3 попыток при конфликте. Round-robin cursor в неизменяемом BackgroundJobRun предотвращает блокирование следующих заданий уже обработанными. Административное чтение backgroundJobs показывает20 проходов; enabled не является доказательством живого процесса.

Проверено:26 policy unit,22 SQL,4 интеграции на отдельной БД; rollback при сбое, параллельность и повтор без дублей. Полный E2E и окончательный локальный запуск нужно сверить по финальному сообщению/отчёту. Миграция20261026110000 сначала применена только к тестовой БД. Старые данные не сбрасывались.
