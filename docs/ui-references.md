## Паттерны для Qosyl

Primer: сравнимые строки, понятная навигация и явные состояния; применимо к каталогу и модерации. Carbon: управляемая плотность и различие пустого/ошибочного состояния; полезно для очереди редактора. Atlassian: согласованный словарь действий и маршрутов; применимо к переходам заказчика и студента. Это открытые системные материалы, не изучение закрытого интерфейса всех перечисленных продуктов.

Текущие дополнительные первоисточники: [Playwright accessibility](https://playwright.dev/docs/accessibility-testing), [Tailwind Next.js](https://tailwindcss.com/docs/installation/framework-guides/nextjs), [Codex skills](https://learn.chatgpt.com/docs/build-skills), [AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [Anthropic LICENSE](https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/LICENSE.txt), [Vercel guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md). Проверены 26.10.2026.

Vercel guidelines содержат контекстные советы, а не нормы: не принимать автоматически Title Case для русского текста, autocomplete=off для всех не-auth полей, обязательную virtualization после 50 строк или overflow-hidden как лечение layout. Native button не требует ручного дублирования клавиатурных handlers. Применять браузерную семантику и измерять реальную проблему. Поддержка React 19 в peer-диапазоне не доказывает доступность и корректность каждого компонента.
