# План реализации MVP

Источник требований: `docs/TZ_Codex_Student_Marketplace_MVP_v2.md`, 25.10.2026.
Исходные исследовательские материалы и опросник сохраняются без изменений.

1. **Bootstrap**: Next.js App Router, strict TypeScript, PostgreSQL/Prisma, управляемая миграция, безопасный локальный запуск, seed 8 явно демонстрационных заказов. Проверка схемы и миграции.
2. **Auth & roles**: Better Auth, email/пароль, защищенные сессии, восстановление через локальный почтовый ящик, onboarding двух рабочих ролей, серверные guards, профили. Проверка входа и запрета административной эскалации.
3. **Marketplace**: черновик, модерация с причиной, каталог с серверными фильтрами, бесплатный отклик/редактирование/отзыв, выбор одного исполнителя в транзакции. Проверка публичной проекции и ownership.
4. **Workflows**: неизменяемые версии условий, два подтверждения, чек-лист, сдача ссылок, конкретные правки по критериям, приемка, отдельные заявления об оплате, два подтверждения закрытия, аудит. Проверка полного пути и запрещенных переходов.
5. **Portfolio & admin**: согласование публичной видимости, разделение self-reported/client-confirmed, отзывы, жалобы, блокировки с причинами, уведомления и честные агрегаты. Проверка изоляции приватных данных.
6. **QA**: Vitest, Playwright на реальном PostgreSQL, desktop/tablet/mobile, typecheck, ESLint, production build, документация и сценарий демонстрации.

По каждому этапу фактические проверки и ограничения фиксируются в `docs/qa-report.md`. Статус готовности определяется результатом проверок, а не наличием файлов.

## Итог 25.10.2026

Позднее уточнение владельца: демонстрируем локально, облако приобретаем после финансирования. Запуск — `npm run demo` / `START_DEMO.cmd`, инструкция — `local-demo.md`. Готовность локального MVP определяется обязательным P0 и Definition of Done ТЗ; P1 и внешние условия не выдаются за завершенные. Последующие проверки фиксируются отдельно в `qa/` и не подменяют исторический прогон ниже.

Этапы 1–6 выполнены в пределах локального MVP. Итоговые проверки: strict TypeScript, ESLint, production build, 11 unit-тестов и 13 сквозных тестов проходят. Подробные доказательства, найденные исправления, снимки экранов и непроверенные внешние условия — в `qa-report.md`. Публичный production и P1 не объявляются завершенными.
