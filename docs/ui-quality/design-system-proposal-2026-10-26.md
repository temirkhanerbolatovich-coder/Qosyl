# Дизайн-система Qosyl

Статус: подготовленная спецификация v0.1, 26.10.2026. Это направление будущего внедрения, а не описание уже изменённого UI. Токены в [tokens.json](tokens.json) не подключены к приложению. Текущие значения остаются в `src/app/globals.css`.

## Продукт и выбранное направление

Студент сравнивает ограниченные задачи, оценивает результат/часы/оплату и откликается. Заказчик формулирует проверяемый результат, выбирает исполнителя и принимает работу. Модератор проверяет предложения, источники и права. Возможности и новости дополняют биржу; они не должны затмевать каталог проектов.

Рассмотрены три направления. «Рабочая биржа» сохраняет узнаваемый синий акцент, светлые поверхности и делает условия заказа главным визуальным объектом. «Редакционный карьерный журнал» использует тёплые поверхности, крупную типографику и материалы, но смещает акцент к контенту. «Операционная консоль» даёт плотные строки/таблицы и много фильтров, хорошо подходит модератору, однако тяжела для первого отклика студента. Выбрано первое; третье применяется как режим плотности admin, а не новый бренд.

Основа идентичности — измеримый результат задачи, прозрачные условия и человеческий язык. Не нужны орбы, градиентные фоны, декоративные графики и пустые KPI. Нумерация реального процесса допустима. Карточки нужны для сопоставимых проектов, а не для каждого абзаца текста.

## Токены

| Роль | Предложение | Использование |
| --- | --- | --- |
| Canvas / surface | #f7f8fa / #ffffff | Фон и рабочая поверхность |
| Text / muted | #18263c / #536176 | Основной и вспомогательный текст; muted темнее текущего #667387 |
| Action / hover | #2557d6 / #1b42a8 | Основное действие, ссылки, focus |
| Decorative border / control border | #e2e7ee / #718096 | Светлая линия не является достаточным обозначением границ input |
| Success | #237357 на #e4f4ee | Только подтверждённое успешное состояние |
| Warning | #795300 на #fff4dc | Предупреждение, требующее внимания |
| Danger | #b42318 на #fef3f2 | Ошибка или риск разрушительного действия |

Для каждой контрастной пары есть исполняемая проверка `npm run ui:tokens`; результат записывается в `outputs/ui-quality/token-contrast.json`. Проверка пары не доказывает контраст каждого пикселя приложения: наследование, opacity и соседние поверхности проверяются отдельно. Статус выражается текстом/иконкой вместе с цветом.

Шаги отступов: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px. Радиус: 4 для небольших меток, 8 для controls, 12 для групп/карточек; круг только для аватара и действительно круглой кнопки. Тень слабая для поднятых элементов, не вокруг каждого блока. Focus — 3 px action с offset 3 px; проверить незакрытость sticky-элементами.

## Типографика и сетка

На первом внедрении сохраняется локальный Arial/Helvetica/sans-serif, без скачивания шрифтов. Проблемы иерархии решаются кеглем, весом и длиной строки, а не обязательной сменой гарнитуры. Предлагаемые размеры: подпись 12/18, вторичный UI 14/20, основной 16/24, карточка 18/24, раздел 24/30, страница 32/38, публичный заголовок максимум 44/48. Подпись 12 px не используется для основного результата/бюджета/ошибки. Текстовое описание ограничивается приблизительно 65–75 символами по ширине, числа бюджета выравниваются для сканирования.

Контейнер максимум 1240 px, горизонтальные поля 16 px на узком экране, 24 на планшете, 32 на большом. При 375 px одна колонка и компактное раскрытие фильтров с видимым числом активных условий. На 768 px сетка зависит от фактической ширины карточки, а не правила «это всегда mobile». На 1440/1920 px содержимое не растягивается бесконечно. Рабочие ориентиры для проверок — 375/768/1440/1920 и границы существующих media queries 600/800/850/1100/1440. Использовать Grid для страниц, Flex для групп действий, minmax(0,1fr), min-width:0 и перенос длинных RU/KZ строк.

## Компоненты и состояния

| Семейство | Содержание и поведение |
| --- | --- |
| ProjectCard / строка | Название задачи, результат, бюджет ₸, часы, формат/город, срок, статус, отдельная метка ДЕМО. Нет выдуманной верификации заказчика |
| Filters | Сохранение query/deep link, явные label, активные условия и сброс; не терять ввод при раскрытии |
| PageHeading | Одна основная цель, краткий контекст, одно приоритетное действие; не повторять бессодержательный uppercase eyebrow |
| FormField | Постоянный label, помощь, ошибка рядом с полем, связь aria-describedby, input autocomplete/type, сохранение ввода при ошибке |
| Action | Навигация — link, изменение — button; pending защищает от дубля, disabled объясняется контекстом |
| Status | Чёткая подпись из действующего доменного enum; не менять юридический смысл статуса ради цвета |
| Empty / loading / error | Что произошло, что доступно дальше, retry при реальной возможности; не показывать ноль как завершённую загрузку |
| Table / admin list | Заголовки, сравнимые колонки, доступные row actions, прокрутка только собственного table region при необходимости |
| Opportunity | Источник, дата/неизвестный срок, категория, ссылка; публикация и право участия остаются редакционными решениями |

Для каждого реализуемого компонента нужны default/focus/hover/disabled/pending/error и применимые empty/success. Выделение общего компонента оправдано повторением поведения; каталог Storybook откладывается до появления устойчивых primitives. Новые диалоги требуют возврата focus, Escape и корректной семантики; существующая страница не превращается в dialog ради красоты.

## Проверяемая доступность и движение

Цель — WCAG 2.2 AA; обычный текст 4.5:1, крупный 3:1 по соответствующим критериям. Практический размер основных touch controls 44×44 CSS px; норматив AA Target Size (Minimum) — 24×24 с условиями/исключениями, эти два ориентира не подменяют друг друга. Ссылки узнаются без одного только цвета. Клавиатура, screen reader, reflow/zoom и реальная мобильная среда требуют отдельных проверок.

Только обратная связь на действие и изменение состояния; обычный transition 120–180 ms, без entrance у каждой карточки. Существующий prefers-reduced-motion сохраняется. Не добавлять Motion ради одной fade-анимации.

Основания: [WCAG 2.2](https://www.w3.org/TR/WCAG22/), [APG](https://www.w3.org/WAI/ARIA/apg/), [Primer checklist](https://primer.style/accessibility/tools-and-resources/checklists/engineering-checklist/), [референсы и даты проверки](../ui-references.md). Это авторская спецификация для Qosyl, без копирования чужого бренда или макетов.
