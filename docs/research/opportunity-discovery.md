# Поиск возможностей для студентов: источники и бесплатные парсеры

Дата проверки: 26.10.2026. Это исследование и проект расширения, не отчёт о готовой интеграции. Новые сборщики не установлены и к основной БД не подключены.

## Требуемый охват

Статьи и новости, гранты и стипендии, практика и стажировки, конкурсы, мероприятия, программы региональных хабов и другие возможности для студентов всех специальностей. Казахстан — начальная география; русский, казахский, английский. IT не является обязательным признаком релевантности.

## Проверенное текущее состояние Qosyl

Существуют manual/RSS/Atom источники, закрытая очередь, worker, нормализация, история редакций и явная модерация перед публикацией. Импорт не создаёт заказ Project и не означает согласие автора. Категории сейчас: hackathon, competition, internship, event, other. HTML/Telegram/Instagram адаптеров и полноценного поиска по каталогу возможностей пока нет.

## Бесплатные инструменты

| Инструмент | Назначение | Проверка и ограничения |
| --- | --- | --- |
| [Crawlee](https://github.com/apify/crawlee) | HTML и динамические сайты; Node.js, Cheerio, Playwright | Исходники, Apache-2.0, локальный запуск; не требует облака Apify. Нужны правила извлечения под источник. Для текущего TypeScript стека основной кандидат. |
| [Trafilatura](https://trafilatura.readthedocs.io/en/latest/) | Текст и метаданные статей/новостей, sitemap/feed discovery | Проверена документация автора; Python, дополнительный runtime при включении. Сам по себе не гарантирует правильные дедлайны/условия участия. |
| [RSSHub](https://github.com/DIYgod/RSSHub) | Преобразование поддерживаемых источников в RSS | Есть [код Telegram channel route](https://github.com/DIYgod/RSSHub/blob/master/lib/routes/telegram/channel.ts). Репозиторий AGPL-3.0: условия лицензии учитывать отдельно. Доступность конкретного канала нужно тестировать. Нельзя подключать localhost RSSHub путём снятия SSRF-защиты существующего fetcher. |
| [Instaloader](https://instaloader.github.io/) | Известные Instagram-профили, подписи и метаданные | Исходники MIT. Не доказан как глобальный поиск по ключевым словам. Вход/лимиты могут потребоваться; отдельная сессия и точный список аккаунтов. Для Qosyl медиа скачивать не требуется. |
| [browser-act Threads extractor](https://github.com/browser-act/skills/tree/main/solutions/social-listening/threads-keyword-search) | Пример извлечения поисковой выдачи Threads | Реальный extraction script, репозиторий MIT. Это компонент браузерного workflow, не готовый серверный API. Сам код не запускался; обычный поиск в авторизованном браузере проверен и показывает чужие посты. |
| [zrkluke/threads-crawler](https://github.com/zrkluke/threads-crawler) | Поиск/профили/метки Threads, локальный Apify Actor | Исходники и инструкции локального запуска есть. Лицензия в GitHub metadata отсутствует, LICENSE в корне не найден. Поэтому не включать чужой код в Qosyl до уточнения лицензии. По умолчанию фильтрует Traditional Chinese; для других языков нужен postLanguageFilter=any. |

[Apify Free](https://apify.com/pricing) — сервис с $5 кредитов, а не бессрочно бесплатные неограниченные парсеры. [cliqtomedia/threads-scraper](https://apify.com/cliqtomedia/threads-scraper) заявляет поиск без входа; сам Actor не запускался. [logiover/threads-scraper](https://github.com/logiover/threads-scraper) содержит документацию к Actor, а не исходный сборщик. Старый [junhoyeo/threads-api](https://github.com/junhoyeo/threads-api) архивирован в 2023 году и не рекомендуется как основа.

Проверка показала, что t.me/s/astanahub содержит лишь канал с 86 подписчиками и запись о создании. Этот handle нельзя автоматически считать официальным каналом Astana Hub.

## Архитектура предлагаемого расширения

Реестр источников → отдельный ограниченный сборщик RSS/HTML/публичного канала → единая нормализация → поиск и фильтры → закрытая очередь проверки → публикация. Предпочитать собственный RSS/API источника, затем обычный HTML; браузер запускать для страниц, которым нужен JavaScript. Не добавлять все инструменты одновременно.

Для каждого материала хранить исходный URL, источник, дату обнаружения, дату публикации (если известна), тип, тему/специальности, регион/онлайн, язык, известный дедлайн, требования участия, стоимость/оплату если явно указаны, статус проверки. Статья/новость должна отличаться от возможности подать заявку. Неизвестные даты и условия оставлять неизвестными.

Фильтры: запрос, тип, регион/онлайн, специальности, язык, срок подачи. Направления должны включать инженерные и строительные, педагогические, медицинские, экономические/правовые, гуманитарные/языковые, дизайн/медиа/культуру, сельское хозяйство, сервис/туризм и IT. Неизвестное направление не отбрасывать как нерелевантное.

RSSHub и Python-библиотеки не подключать за счёт ослабления сетевых ограничений. Сохранить лимиты размера/времени, фиксированные домены источников, защиту локальной сети, паузу при ограничениях провайдера, историю и ручную модерацию. Для социальных сайтов читать только доступные страницы, без обхода CAPTCHA и без экспорта существующих браузерных cookies в сторонние сервисы.

## Приоритет внедрения

1. Реестр источников и общая схема: гранты, стипендии, новости/статьи, стажировки, мероприятия, конкурсы, обучение. Поиск по накопленным данным и фильтры специальностей/регионов.
2. Проверить реальные RSS/HTML Astana Hub, нескольких региональных хабов, Enbek и выбранных госразделов; импортировать в существующую закрытую очередь.
3. Подключить конкретные публичные Telegram-каналы.
4. Отдельно испытать браузерный Threads и Instagram-аккаунты; не блокировать остальные источники их ограничениями.

## Приёмка будущей реализации

Настоящие материалы минимум из трёх различных семейств источников, включая не-IT направление; исходные ссылки и фактические даты; повторный импорт без дублей; истёкший дедлайн не показывается как действующий; недоступный источник отмечен ошибкой, не «0 возможностей»; неизвестная специальность не исключается; API и UI поиска дают согласованные результаты. Опубликованные материалы не превращаются автоматически в заказы или согласие организатора.

В этой исследовательской итерации проверены страницы авторов инструментов, GitHub metadata лицензий и наличие исходников. Чужие парсеры не устанавливались, сбор возможностей Qosyl не расширен и новые источники не включены.
