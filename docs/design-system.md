# Дизайн-система Qosyl 1.0

Внедрена 26.10.2026 по явному запросу пользователя после инфраструктурного этапа. Направление — практическая студенческая биржа Deep Blue + Teal. Каталог, условия заказа и действия участников важнее декоративных блоков. Новые API, роли и бизнес-правила не вводились.

## Источник токенов

Единственный редактируемый источник — [src/lib/design-tokens.json](../src/lib/design-tokens.json). Команда `npm run ui:tokens` генерирует `src/app/design-tokens.css` и проверяет контраст обеих тем; `node scripts/generate-design-tokens.mjs --check` обнаруживает рассинхронизацию. Старые имена --blue/--paper/--ink сохранены как алиасы для существующих классов, а не вторая палитра. В globals.css и design-system.css нет HEX-цветов.

## Темы и загрузка

Переключатель в шапке: «Светлая / Тёмная / Система». На узком экране он доступен в раскрытом меню. Preference хранится в localStorage под ключом qosyl-theme, не связана с аккаунтом и не содержит секретов. Режим System использует prefers-color-scheme и реагирует на изменения ОС. Изменения другой вкладки синхронизируются через storage event.

Статический head-script до содержимого устанавливает data-theme и data-theme-preference. При недоступном storage выбирается System; ручной выбор продолжает работать для текущего документа. CSS имеет системный fallback без JS, а color-scheme согласует native inputs/scrollbars с темой. suppressHydrationWarning ограничен html с преднамеренным предзагрузочным атрибутом. CSP не ослаблялась.

## Логотип и шрифты

Обязательный логотип пользователя — [public/brand/qosyl-logo.jpg](../public/brand/qosyl-logo.jpg). Это побайтовая копия исходного JPG, SHA-256 `F9510B8F3C9262AA816927E4DF4BD9F6B45B2C698D7BBA51C9645A6F89458DDD`. Используется в шапке, подвале и metadata icon; временный символ q больше не используется. В dark сохраняется исходный белый фон, без инверсии или перерисовки. Оптимизированную доставку изображения выполняет Next Image.

Manrope — заголовки/числа, Inter — интерфейс, формы и текст. Шрифты локальные WOFF2 через next/font/local, font-display:swap, два семейства. Вместе 404064 байта; сеть Google не нужна при сборке и посещении. OFL-лицензии и [происхождение](../src/app/fonts/SOURCES.md) включены. У Manrope есть русская кириллица, но не все казахские буквы; они переходят к Inter. Автоматический Arial fallback Manrope отключён для явного порядка Manrope → Inter → sans-serif.

Body 16 px / 1.6; основной UI 14–16, caption не меньше 12. Hero — fluid 32–38 mobile и до 56 desktop. H1 — 32–44, H2 — 24–32; в компактных карточках собственные роли 18–20. Высота строк заголовков 1.12–1.35 по роли. Бюджеты и показатели используют tabular numerals. Текстовые блоки ограничиваются удобной шириной, длинные названия переносятся.

## Layout и компоненты

Spacing: 4/8/12/16/20/24/32/40/48/64/80/96 px; radius: 6/10/12/16. Контейнер максимум 1280 px, mobile поля 16. Grid/Flex сохраняют исходную структуру. Меню раскрывается до 1024 px, чтобы theme selector и действия не переполняли шапку. Основные controls имеют область около 44 px. На мобильном фильтры и формы помещаются в одну колонку; таблицы/рабочие навигации могут иметь собственную прокрутку, не всей страницы.

Button поддерживает primary (по умолчанию), secondary, outline, ghost и destructive/danger. Общие стили охватывают inputs/select/textarea/checkbox/radio, панели, badges/status, tabs/navigation, alerts, skeleton/empty, pagination и существующие рабочие списки. Не добавлены неиспользуемые Dialog/Tooltip-функции и второй UI-kit; существующие native controls сохраняют браузерное управление focus/клавиатурой. Новому сложному widget требуется отдельная проверка поведения.

Главная показывает проекты до блока внешних возможностей, рабочий процесс и честный FAQ без вымышленных результатов. Карточки содержат условия, бюджет, навыки, срок и явный переход. Публикации показывают источник, категорию, дату либо неизвестную дату. Приватность, ДЕМО, правила публикации, согласия и ограничения оплаты сохранены.

Анимации функциональны, обычно 180 ms; reduced-motion отключает их. Фокус обозначен 3 px с offset 3. Проверки токенов и axe не равны WCAG-сертификации: keyboard, zoom, реальные устройства и пользовательское исследование оцениваются отдельно. [Проверки и ограничения внедрения](qa/design-system-implementation.md).
